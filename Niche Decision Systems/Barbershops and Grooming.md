# Barbershops And Grooming Decision System

This is not a template. It is a decision system.

## Default User Goal

Most visitors want to:

- judge haircut quality
- see prices
- choose a barber
- trust the place
- book quickly

## Primary CTA

Book appointment.

Secondary actions should not compete with booking.

## Candidate Sections

Usually useful:

- hero
- team/barbers
- services/prices
- results/gallery
- FAQ
- location/contact
- booking
- footer

Optional:

- trust strip
- reviews
- long brand story

## When To Use Team

Use team if customers can choose a barber.

Team should build trust through:

- real photo
- name
- role
- short proof/quote

Avoid stuffing team cards with full price lists.

## When To Use Reviews

Use reviews if they are specific and can be integrated elegantly.

Remove reviews if they look like generic cards or weaken the premium visual flow.

## Services

Prefer a single centered list with:

- service name left
- time/details below
- price right
- clean divider

Use barber tabs if each barber has different services/prices.

Avoid uneven two-column service grids.

## Visual Directions

Choose based on the brand:

### Editorial Luxury

Use if photos are monochrome, clean, serious, or premium.

Use:

- black and cream contrast
- elegant serif display
- precise sans labels
- slow motion
- real result photos

### Urban Street

Use if brand feels younger, louder, fashion-driven, or social.

Use:

- stronger contrast
- bold sans/condensed type
- sharper movement
- more energetic gallery

### Clean Local

Use if brand is friendly, practical, and family-friendly.

Use:

- warmer neutrals
- clear service cards/list
- softer copy
- less dramatic motion

## Avoid

- generic barber pole cliches
- playful blobs unless the brand is playful
- fake luxury gold if no brand evidence supports it
- too many badges
- testimonials that look pasted in
- overcomplicated booking in cold demos
