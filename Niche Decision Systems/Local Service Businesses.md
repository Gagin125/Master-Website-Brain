# Local Service Businesses Decision System

This applies to businesses where the user usually wants to trust, call, book, visit, or request service.

Examples:

- salons
- clinics
- repair shops
- studios
- gyms
- dentists
- tutors
- local agencies

## Default User Goal

Most visitors want to know:

- what you do
- where you are
- whether you are trustworthy
- what it costs or how to start
- how to contact/book quickly

## Primary CTA

Choose one:

- call
- book
- request quote
- visit
- message

Do not split attention unless there are two truly different user intents.

## Candidate Sections

Usually useful:

- hero
- services
- proof/results
- team if people matter
- reviews if specific and credible
- FAQ
- location/contact
- final CTA
- footer

Optional:

- full about story
- process section
- pricing table
- portfolio/gallery

## Trust Rules

Use the strongest available proof:

- real photos
- real reviews
- visible results
- certifications
- clean pricing
- clear location
- specific process

Do not add generic badges if real proof is stronger.

## Design Rules

The design should match the business type and price point.

High-trust local service sites usually need:

- clear hierarchy
- readable service information
- strong mobile experience
- fast CTA access
- no fake luxury
- no vague slogans

## Avoid

- template completeness
- too many equal CTAs
- fake stock imagery
- excessive theory
- overbuilding before user interest
- hiding practical details users need before contacting
