# Restaurants Decision System

This is not a template. The restaurant type decides the site.

## Default User Goal

Visitors usually want:

- atmosphere
- menu
- reservation
- location
- opening hours
- proof of quality

## Primary CTA

Reserve a table.

Secondary:

- view menu
- directions

Do not make directions visually equal to reservation unless location is the main conversion goal.

## Candidate Sections

Usually useful:

- cinematic hero
- about/brand story
- menu preview
- gallery
- private events if offered
- location/contact
- final reservation CTA
- footer

Optional:

- reviews
- chef/team
- full menu page
- event packages

## Visual Directions

### Fine Dining / Premium

Use:

- dark or ivory editorial canvas
- refined serif typography
- real food/interior photos
- slow transitions
- restrained CTAs

### Casual Restaurant

Use:

- clearer menu emphasis
- warmer copy
- less cinematic abstraction

### Hotel Restaurant

Use:

- location clarity
- reservation confidence
- private event positioning
- polished but not fake-exclusive tone

## Rules

- Hero CTA can be reservation.
- End CTA should usually reinforce reservation, not switch to unrelated action.
- Location section can include directions, but it should not overpower booking unless finding the venue is the main barrier.
- Full menu page should be crawlable HTML, not just PDF.
- Include structured data and local SEO basics for production.

## Avoid

- too much "gastronomy" language if it sounds heavy
- generic luxury gold
- wide hero text that becomes unreadable on mobile
- video backgrounds without poster/performance fallback
- menu pages with no language switch
