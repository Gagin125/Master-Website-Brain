# Gallery, Reviews, Location, Booking

## Gallery / Results

Use to prove the product or atmosphere.

Rules:

- show the result clearly
- crop for the subject, not the layout
- do not let hover pause break carousel continuity
- avoid repeated or weak images

Carousel hover should slow down, not jump or reset.

## Reviews

Use when reviews improve trust without weakening design.

Rules:

- real names
- specific claims
- clear source
- translation labels if translated

Remove reviews if they look generic or pasted in.

## FAQ

Use to remove friction.

Rules:

- short questions
- short answers
- smooth open/close animation
- no helper paragraph unless it adds value

## Location

Use for every local business.

Rules:

- address
- hours
- phone/email/social
- directions
- map styled to fit the site

Avoid scattered contact details and default bright maps inside dark layouts.

## Booking

Use when booking is the primary CTA.

Rules:

- make booking feel like the final destination
- show clear steps
- allow back navigation
- secondary phone option should be quieter than primary booking flow
- do not build real backend for cold demos unless requested
