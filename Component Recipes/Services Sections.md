# Services Sections

Services sections must make choosing easy.

## Best Default

Use a single centered list when services have prices.

Structure:

- service name
- short detail/time if useful
- price aligned right
- subtle divider

## Use Tabs When

- categories are meaningful
- different people have different services
- menu groups are too large for one list

Tabs should not move the whole navigation or layout.

## Animation

When changing tabs:

- active underline should slide, not jump
- list should fade/slide down in a calm stagger
- avoid instant content swaps

## Avoid

- uneven two-column lists
- prices in random colors
- repeated footnotes under every item
- too many service categories
- hiding prices if price confidence matters
