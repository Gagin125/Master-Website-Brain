# Just My Type - Extracted Principles

Source: Simon Garfield, *Just My Type*

Folder: Font Psychology & Visual Vibes

Extraction status: usable PDF text extraction.

Purpose of this note: extract practical lessons about font personality, cultural associations, brand perception, and choosing typefaces for websites.

---

## Core Thesis

Fonts carry history, associations, tone, and personality. They do not simply display words; they shape how words are felt.

For websites:

> A typeface is a brand voice before the visitor reads the sentence.

---

## Website-Relevant Ideas

### 1. Fonts Have Cultural Baggage

Garfield repeatedly shows that famous typefaces come with associations:

- Helvetica: Swiss modernism, corporate neutrality, order, ubiquity.
- Gill Sans: British institutional warmth and awkward historical baggage.
- Futura: geometric modernity, progress, future-facing clarity.
- Baskerville: literary refinement, elegance, credibility.
- Gotham: civic confidence, contemporary American public voice.
- Comic Sans: casual informality used in the wrong contexts until it became a signal of amateurism.

Website translation:

- A font is never emotionally blank.
- Even "neutral" fonts can signal a culture or era.
- Font choice must match the brand's actual world.

Rule:

> Choose fonts for associations, not only shapes.

---

### 2. Context Can Make A Good Font Bad

Comic Sans is the obvious example: it was designed for a specific informal context, then became disliked because it was used everywhere it did not belong.

Website translation:

- A font can be well-designed and still wrong for the brand.
- A playful font can work for a children's product and fail for a law firm.
- A luxury serif can work for fine dining and feel fake for a small casual cafe.

Rule:

> Font appropriateness matters more than font popularity.

---

### 3. Legibility And Readability Are Different

The book distinguishes the recognizability of letters from the ease of reading larger text.

Website translation:

- A typeface can be legible in a logo but tiring in paragraphs.
- Display fonts should not be used for dense body copy.
- Beautiful letterforms do not guarantee comfortable reading.

Practical rule:

> Test fonts in the actual job: nav, button, paragraph, menu, caption, hero.

---

### 4. Familiarity Can Signal Trust Or Boredom

Common fonts can feel safe because people know them. But overused fonts can also feel generic.

Website translation:

- Familiar fonts are good for utility and clarity.
- Distinctive fonts are useful for brand memory.
- A strong website often combines one expressive brand typeface with one reliable reading typeface.

Bad pattern:

- Every project uses the same default sans.
- Every premium project uses the same editorial serif without brand reason.

---

### 5. Typefaces Shape Brand Memory

Garfield's stories show how typefaces become attached to brands, eras, movements, tools, and public events.

Website translation:

- Typography should be part of brand identity.
- Repeated type choices create memory.
- Inconsistent typography weakens recognition.

Rule:

> A website's type system should be memorable enough to support identity, but disciplined enough to stay readable.

---

### 6. The Pull-Down Font Menu Is Dangerous

Modern tools make many fonts available, but availability creates temptation.

Website translation:

- More font options do not mean better design.
- AI tools often overmix fonts or choose "vibes" without system logic.
- Font selection should be deliberate and limited.

Practical rule:

> Use fewer fonts, with clearer jobs.

---

## Practical Website Rules Extracted

- Every font carries associations.
- Match typeface personality to brand truth.
- Test fonts in their actual UI/content roles.
- Do not use display fonts for reading-heavy text.
- Use familiar fonts for clarity when needed.
- Use distinctive fonts for brand memory when justified.
- Avoid fonts with cultural baggage that conflicts with trust.
- Keep the type system limited and consistent.

---

## Font Personality Translation

These are tendencies, not laws:

- Elegant serif: editorial, literary, refined, traditional, premium.
- Geometric sans: modern, structured, rational, clean, sometimes cold.
- Humanist sans: approachable, readable, warm, practical.
- Grotesque/neo-grotesque sans: neutral, corporate, modern, restrained.
- Script: personal, expressive, risky, often poor for UI.
- Display type: memorable, expressive, risky if overused.
- Monospace: technical, archival, mechanical, code-like, utilitarian.

Context can reverse these effects.

## Web Applications

### Restaurants

- Fine dining can use elegant serif display plus restrained sans details.
- Casual cafes need warmth and readability, not fake luxury.
- Menus need practical scanning more than visual drama.

### Local Businesses

- Use type that feels trustworthy, human, and easy to read.
- Avoid overly trendy type that dates quickly.

### SaaS / Tools

- Use readable sans systems.
- Add personality through headings, interactions, illustrations, or selected display moments.

### Luxury Brands

- Use restraint.
- Use type with confidence.
- Avoid overdecorated scripts or excessive thinness that hurts readability.

---

## AI Agent Instructions

When applying this book:

1. Identify the brand's real personality.
2. Pick typefaces that support that personality.
3. Check whether the font has conflicting cultural baggage.
4. Assign clear roles: display, body, UI, labels.
5. Limit the system.
6. Test the font in real responsive layouts.
7. Do not pick a typeface just because it feels premium in isolation.
