# Folder Synthesis - Typography Mechanics & Rules

Sources processed:

- Robert Bringhurst, *The Elements of Typographic Style*
- Ellen Lupton, *Thinking with Type*
- Jost Hochuli, *Detail in Typography*  
  Note: Hochuli PDF extraction was poor, so its note is principle-level only.

Purpose of this note: synthesize practical typography rules for future websites, design systems, and AI-agent design decisions.

---

## What These Books Agree On

### 1. Typography Is A System, Not A Font Choice

The books agree that type quality comes from relationships:

- typeface
- size
- weight
- line length
- line-height
- alignment
- spacing
- grid
- hierarchy
- rhythm

Website implication:

> Choosing a beautiful font does not save bad typography.

---

### 2. Readability Is Built From Measure And Leading

Readable body text requires controlled line length and line spacing.

Website implication:

- Do not let body text run across huge desktop widths.
- Do not use tight line-height for long paragraphs.
- Do not rely on tiny thin text for important content.
- Adjust body text differently from display headings.

Practical rule:

> Body text needs a container, not just a font size.

---

### 3. Hierarchy Requires Contrast

Hierarchy is built through contrast in size, weight, spacing, alignment, color, and position.

Website implication:

- If everything is large, nothing is important.
- If headings and body text are too similar, scanning fails.
- If nav text competes with the logo, brand hierarchy weakens.

Rule:

> Typography should tell the eye what matters first, second, and third.

---

### 4. Grids Create Order

Lupton emphasizes grids; Bringhurst emphasizes proportion and page structure. Both point toward ordered relationships.

Website implication:

- Use grids for menus, galleries, cards, pricing, and contact sections.
- Break the grid only after structure exists.
- Responsive collapse should preserve meaning.

---

### 5. Details Signal Craft

Hochuli and Bringhurst especially support the idea that small details matter.

Website implication:

- Button text alignment matters.
- Price alignment matters.
- Label spacing matters.
- Captions matter.
- Mobile line breaks matter.
- Letter spacing must be controlled.

Rule:

> Users may not name typographic errors, but they feel them.

---

## Strong Principles Worth Keeping

1. Build type systems, not isolated styles.
2. Use controlled body text measure.
3. Match line-height to measure and font size.
4. Use scale contrast to create hierarchy.
5. Use display fonts only for display jobs.
6. Prefer left-aligned body copy for reading.
7. Use centered text sparingly.
8. Use grids to organize relationships.
9. Use letter spacing carefully, mostly for small uppercase labels.
10. Audit micro-spacing before calling a design finished.

## Practical Web Typography Rules

### Body Copy

- Keep line length comfortable.
- Use line-height around 1.45-1.75 depending on typeface and measure.
- Avoid ultra-light weights for important text.
- Use paragraph spacing consistently.
- Left-align most reading text.

### Hero Headings

- Hero type can be expressive.
- Avoid accidental 5-7 line breaks on desktop.
- Keep line-height tight but not colliding.
- Make headline width intentional.
- Make mobile line breaks feel designed.

### Navigation

- Brand/logo text needs clear priority.
- Nav labels should be smaller and functional.
- CTA and language toggle should not overpower the logo.
- On mobile, nav hierarchy must stay calm and obvious.

### Menus And Prices

- Item name, description, and price need a repeatable system.
- Prices should be easy to scan.
- Descriptions should be quieter.
- Lines/dots/rules can clarify relationships when subtle.
- Tabs should fit comfortably and not wrap awkwardly.

### Cards

- Card headings should not use hero-scale type.
- Text should not overflow.
- Captions and labels should be secondary.
- Consistent padding matters.

### Galleries

- Captions should not fight images.
- Crops should protect the subject.
- Grid rhythm should support the photos, not force them.

## Common AI Typography Mistakes

- Huge headings everywhere.
- Too many font weights.
- Letter spacing used as decoration.
- Body copy too wide.
- Centered paragraphs everywhere.
- Thin low-contrast text.
- Hero text wrapping awkwardly.
- Nav logo same size as links.
- UI labels too small.
- Price/menu rows visually disconnected.
- Mobile text overflowing buttons or cards.

## Contradictions And Tensions

### Tension 1: Expressive Type Vs Readability

Beautiful display type can create brand feeling, but it fails when used for reading.

Resolution:

- Use expressive type for short headings.
- Use readable type for paragraphs, menus, forms, and practical details.

---

### Tension 2: Strict Grid Vs Human Warmth

A perfect grid can feel cold. Too much looseness can feel amateur.

Resolution:

- Build a strong grid.
- Add controlled variation through images, section rhythm, and spacing.

---

### Tension 3: Premium Restraint Vs Information Density

Premium design needs breathing room, but websites also need useful information.

Resolution:

- Use hierarchy, not omission.
- Put essential information in calm, structured layouts.

---

## What To Promote Into The Active Brain Later

Candidate durable rules:

- Typography is a system of relationships, not a font choice.
- Body text needs controlled measure.
- Hierarchy must be obvious before reading.
- Display type and reading type have different jobs.
- Grids create order; intentional breaks create character.
- Small typographic details are trust signals.
- Mobile typography must be checked explicitly.
- Avoid centered paragraphs and full-width body copy.
- Price/menu typography is information design.

---

## What Should Stay As Reference Only

Do not promote these as universal rules:

- Any single exact line-length number as a rigid law.
- Print-only rules without web adaptation.
- Always use serif for premium.
- Always use sans for modern.
- Always use a strict baseline grid on web.
- Always avoid expressive typography.

Typography rules need context: brand, content, device, language, and reading task.

## AI Agent Application Checklist

When designing a site:

### System

- What are the text roles?
- What is the type scale?
- Which typeface is for display?
- Which typeface is for reading?

### Readability

- Is body text line length controlled?
- Is line-height comfortable?
- Is contrast strong enough?
- Are paragraphs scannable?

### Hierarchy

- Is the H1 clearly primary?
- Are section headings distinct?
- Are labels secondary?
- Are CTA labels readable?

### Layout

- Is the grid clear?
- Are alignments consistent?
- Are repeated components stable?
- Are mobile line breaks checked?

### Detail

- Are buttons optically centered?
- Are prices aligned?
- Are captions legible?
- Are nav/logo relationships correct?
- Is letter spacing restrained?

---

## Strongest Folder Principle

Typography is where design stops pretending.

If spacing, hierarchy, line length, alignment, and detail are wrong, the site will feel cheaper even if the colors and photos are good.

> Premium typography is readable structure plus quiet craft.
