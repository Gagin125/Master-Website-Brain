# Geometry of Design - Extracted Principles

Source: Kimberly Elam, *Geometry of Design: Studies in Proportion and Composition*

Extraction quality: usable. The PDF text extraction was strong enough to identify the main principles, but the book is highly visual, so the diagrams themselves are only represented indirectly here.

## Core Idea

Good composition is not random decoration. It often rests on underlying proportional systems that make relationships between elements feel intentional.

For websites, this means layout should not be built by dragging blocks until they "look okay." The page should have a visible or invisible structure: ratios, repeated spacing, aligned edges, consistent modules, and proportionate relationships between image, text, whitespace, and calls to action.

## Key Principles

### 1. Proportion creates visual calm

The book repeatedly studies proportion systems such as the golden section, Fibonacci relationships, root rectangles, and dynamic rectangles.

For web design, the practical lesson is not "use the golden ratio everywhere." The better lesson is:

- elements should have deliberate size relationships
- image frames should not feel arbitrary
- type scale should step naturally
- section heights should feel related to their content
- whitespace should be part of the composition, not leftover empty area

### 2. The golden ratio is useful, not magic

The golden section appears across art, architecture, nature, and historical design systems. It can help create pleasing relationships.

But it should not become superstition. A website does not become premium because a designer mechanically applies `1.618`. It becomes premium when proportion helps the user understand what matters.

Practical rule:

Use proportional thinking, not formula worship.

### 3. Root rectangles and paper systems teach responsive thinking

Root rectangles and the DIN paper system show how proportions can scale while preserving relationships.

This matters for responsive web design:

- desktop, tablet, and mobile should not feel like unrelated designs
- the same visual logic should survive across widths
- image aspect ratios should be chosen intentionally
- cards, panels, and content blocks need stable sizing rules

### 4. Composition depends on relationships, not isolated objects

A heading, image, button, or card cannot be judged alone. It is judged by its relationship to everything around it.

Useful questions:

- Does the image support the headline?
- Does the CTA have enough separation to feel actionable?
- Are related elements close enough together?
- Are unrelated elements far enough apart?
- Does the eye know where to go first?

### 5. Geometry can create invisible order

A page can feel organic and still be structured. The user does not need to see the grid or proportion system consciously. They should simply feel that the page is controlled, balanced, and easy to process.

This is important for "human-made" design:

- breaking symmetry works better when the underlying order is still clear
- editorial layouts can feel alive without becoming chaotic
- asymmetry should still have anchor points

### 6. Repeated ratios create cohesion

When proportions repeat across a page, the design feels like one system instead of disconnected sections.

Examples:

- repeated image aspect ratios
- repeated section padding values
- repeated column relationships
- consistent text block widths
- repeated spacing rhythm

This is one reason "rule of eights" spacing works well in web design: it creates a predictable structural rhythm.

## Website Translation

### Hero sections

The hero should have a clear proportional relationship between:

- headline width
- visual area
- vertical breathing room
- CTA spacing
- hint of next section

Avoid oversized hero text that wraps awkwardly into too many lines. A premium hero often feels better when the headline has enough width to breathe in 2-3 deliberate lines.

### Image-led sections

Images should have chosen aspect ratios. Do not let random source photo dimensions dictate the page.

Use:

- `aspect-ratio`
- fixed responsive frame rules
- `object-fit`
- intentional focal positioning

### Cards and repeated components

Repeated cards should share structural logic. If card sizes, paddings, and type scales drift randomly, the page begins to feel cheap.

### Editorial layouts

Asymmetric layouts should still be based on structural relationships:

- 60/40 split
- 50/50 split
- 12-column spans
- full-bleed image paired with constrained text
- large visual balanced by smaller text block

## Common AI Website Mistakes

- using arbitrary section heights
- using image sizes based only on the file shape
- making every section the same centered stack
- confusing whitespace with lack of structure
- using huge headings without considering line breaks
- making bento grids where every tile feels unrelated
- changing spacing rhythm section by section
- applying "golden ratio" language without a real visual reason

## Candidate Rules For The Brain

- Proportion is a trust signal because it makes a page feel intentional.
- Use proportional thinking, not formula worship.
- Every major element should have a clear relationship to nearby elements.
- Asymmetry still needs invisible order.
- Image aspect ratios must be chosen, not inherited accidentally.
- Repeated ratios and spacing create brand cohesion.
- A premium page should feel composed before it feels decorated.

## Rules Not To Overgeneralize

- Do not force the golden ratio onto every layout.
- Do not assume geometric precision automatically creates emotional warmth.
- Do not let proportion systems override content clarity.
- Do not make every website feel rigid just because grids are useful.
