# Folder Synthesis - Grid Systems & Structural Layout

Sources:
- Kimberly Elam, *Geometry of Design*
- Josef Muller-Brockmann, *Grid Systems in Graphic Design*
- Timothy Samara, *Making and Breaking the Grid*

Purpose: extract reusable website-design principles without overloading the active brain.

## The Main Lesson

Great layout is controlled before it is decorated.

A website feels premium when the user can sense invisible order: alignment, proportion, rhythm, hierarchy, repeated spacing, consistent content widths, and clear relationships between elements.

But a website feels human when that order is not dead. The best layouts combine structure with selective expressive breaks.

## Strong Shared Principles

### 1. Structure creates trust

People may not consciously see the grid, but they feel its presence.

Good structure makes a business feel:

- professional
- deliberate
- easy to understand
- less risky
- worth trusting

Poor structure makes even good content feel cheap.

### 2. Alignment is a silent quality signal

Slight misalignments hurt perceived quality.

Watch especially:

- nav groups
- logo position
- CTA placement
- card edges
- image edges
- menu prices
- section headers
- map/contact layouts

### 3. Proportion matters more than arbitrary sizing

Choose relationships:

- 50/50 split
- 60/40 split
- 12-column spans
- repeated image ratios
- repeated spacing scale
- consistent text measure

Do not let random image dimensions or AI defaults decide the page.

### 4. Grids reduce cognitive load

A grid organizes content before the user has to.

Use strong grids for:

- menus
- hours
- pricing
- service comparisons
- testimonials
- product lists
- contact details
- checkout or booking flows

### 5. Break the grid only with intent

Breaking the grid can create emotion, memorability, or editorial personality.

But random asymmetry looks worse than simple order.

Good grid breaks:

- emphasize a hero message
- create a cinematic gallery rhythm
- make one section memorable
- support brand personality

Bad grid breaks:

- every section has different logic
- important information becomes harder to scan
- mobile layout becomes awkward
- the designer is trying to prove creativity instead of helping the user

## Practical Website Layout Rules

### Heroes

- Keep the headline width intentional.
- Avoid awkward 5-7 line wraps.
- Use image/video composition to support text.
- Make CTA spacing clearly separate but still related.
- Leave a hint of the next section when possible.

### Menus and pricing

- Use strong alignment between item names and prices.
- Connector lines can help the eye connect product to price.
- Descriptions should sit below names, quieter than prices.
- Categories should fit cleanly and not wrap awkwardly.
- Functional menu content should prioritize scanability over visual tricks.

### Contact / Visit sections

- Keep address, hours, contact, and social links in one coherent information system.
- Pair the information block with the map in a clear split.
- Avoid button-like elements that are not clickable.
- Avoid social links that visually fight the section.

### Galleries

- Use a grid, but avoid generic uniform social-media squares if the brand needs atmosphere.
- Vary image spans intentionally.
- Keep gap rhythm consistent.
- Do not stretch photos so products or interiors become unclear.
- Use focal positioning per image when needed.

### Reviews

- Keep review cards aligned and comparable.
- Avoid over-designed cards that compete with the quotes.
- Trust content should be structured enough to scan quickly.

### Responsive behavior

- Desktop can carry more asymmetric structure.
- Tablet needs simpler grouping.
- Mobile needs strong stacking order.
- If translated text changes length, the layout must remain stable.

## AI Agent Instructions

Before building a section, the AI should decide:

1. What is this section's job?
2. Is the content functional, emotional, or mixed?
3. Does it need strict structure or expressive structure?
4. What grid relationship should it use?
5. What should align with what?
6. What spacing rhythm continues from previous sections?
7. What happens on mobile?

Only after that should the AI choose colors, animations, shadows, or decorative details.

## Common AI Layout Failures To Avoid

- centering every section
- using cards everywhere
- changing max-width every section
- making random bento grids
- stretching photos to fit boxes
- letting language switch break navigation
- using creative layouts for practical information
- adding decoration before solving structure
- making every section equally loud
- using whitespace without alignment

## Candidate Rules For The Active Brain Later

- Structure before decoration.
- Alignment is a trust signal.
- Use grids for clarity and grid breaks for emphasis.
- Break the grid only after the grid exists.
- Functional content needs stronger structure than emotional content.
- Proportion should be chosen, not accidental.
- Responsive layout is part of the grid, not an afterthought.
- If a layout cannot survive real content, translation, and mobile, it is not finished.

## Tensions To Remember

### Order vs personality

Too much order can feel sterile. Too little order feels amateur.

Use order as the base, personality as the controlled exception.

### Premium vs playful

Premium often needs restraint, spacing, and alignment.

Playful brands can break structure more, but still need hidden order.

### Desktop creativity vs mobile clarity

Desktop can use dramatic grid variation.

Mobile should reduce drama and protect readability.

## Strongest Current Principle

The grid is not the design. The grid is the discipline that lets the design feel intentional.

When the page has structure, the designer can break structure beautifully. When the page has no structure, every "creative" choice becomes noise.
