# SEO Brain

This note comes from comparing three separate SEO research/audit answers for the Solt Dining website.

The lesson is broader than restaurants: most websites do not need SEO tricks first. They need a technically clean, fast, crawlable, trustworthy site that answers the visitor's intent better than competitors.

## Core Principle

SEO is not a separate decoration layer added after the website is finished.

SEO is:

- Clear page purpose.
- Crawlable structure.
- Fast loading.
- Mobile usability.
- Real business trust signals.
- Helpful visible content.
- Correct metadata.
- Correct language signals.
- Internal links that make sense.
- Conversion paths that are easy to take.

If the SEO advice does not improve one of those things, question it.

## SEO Advice That Is Legit

These ideas are worth reusing on almost every website:

- Make every important page crawlable as a normal HTML page.
- Use clear, unique page titles.
- Write meta descriptions that help humans decide whether to click.
- Use one clear main topic per page.
- Use headings for structure, not decoration.
- Keep navigation links crawlable and understandable.
- Create a `sitemap.xml`.
- Create a simple `robots.txt`.
- Add canonical URLs when pages could be duplicated.
- Use correct `html lang` values.
- Keep language switching and URLs in sync.
- Use hreflang when a site has separate language URLs.
- Compress and properly size images.
- Add useful image alt text.
- Lazy-load non-critical images.
- Do not lazy-load the most important hero/above-fold image if it hurts first impression.
- Optimize video backgrounds with compressed files, poster frames, and fallback behavior.
- Make mobile experience the default quality benchmark.
- Track real conversion actions: bookings, calls, forms, menu clicks, map clicks.
- Add structured data only when it truthfully describes visible page content.
- Build trust with real contact info, real photos, real reviews, real location, real hours, and real business details.

These are boring in the best way. They compound.

## SEO Advice That Needs Context

### "Use keywords in the first 100 words"

Useful only if it happens naturally. Do not force it. The real goal is that the first screen clearly explains what the page is about.

### "Use only one H1"

Usually a good discipline, especially for simple marketing sites. But the deeper rule is not the number itself. The page should have a clear main topic and logical heading hierarchy.

### "Write blogs for SEO"

Only useful if the business can publish genuinely helpful content tied to real search intent. For local restaurants, core pages, menu, location, reviews, photos, and Google Business Profile usually matter more than generic blog posts.

### "Get backlinks"

True, but quality matters. Local press, local directories, hotel/partner links, event pages, and real mentions are useful. Spam links are not.

### "Add schema"

Good when accurate. Schema helps search engines understand the page. It does not magically rank a weak page.

### "AI content is bad"

Too simple. AI-assisted content can be fine if it is reviewed, useful, accurate, and specific. Mass-produced generic AI pages are risky and usually useless.

## SEO Advice To Reject

Do not build around these:

- Keyword stuffing.
- Hidden text for search engines.
- Fake reviews.
- Fake review schema.
- Schema for content users cannot see.
- Duplicate city/location doorway pages.
- Mass AI-generated pages.
- Buying spam backlinks.
- Copying competitor text.
- Creating content just because a tool says a keyword has volume.
- Treating `llms.txt` as a current SEO priority.
- Creating Markdown mirrors of pages for AI bots as a main strategy.
- Obsessing over tiny SEO hacks before fixing crawlability, speed, trust, and conversion.

Rule: if the tactic is mainly for crawlers and not useful to humans, it is probably weak or risky.

## Universal SEO Checklist For Local Business Sites

Use this for restaurants, cafes, salons, shops, clinics, service businesses, and similar local websites.

### Critical

- Website opens correctly on the final domain.
- Important pages are indexable.
- No accidental `noindex`.
- No broken main navigation.
- `robots.txt` does not block important pages.
- `sitemap.xml` exists and lists canonical pages.
- Mobile layout is usable.
- Hero media does not delay first impression too much.
- Contact, address, hours, and primary CTA are easy to find.
- Language state, URL, and document language match.

### High Impact

- Clear title tag for each page.
- Clear meta description for each page.
- One strong H1 per main page.
- Logical H2/H3 structure.
- Real menu/services/products visible as text, not only images or PDFs.
- Real photos with useful filenames and alt text.
- Internal links between homepage, menu/services, gallery/work, contact/location, and booking/contact.
- Structured data for the business type when accurate.
- Google Business Profile aligned with the website.
- Reviews/testimonials presented truthfully.
- Booking, call, email, map, and form actions tracked.

### Medium Impact

- Add FAQ only if real questions exist.
- Add deeper service/product pages only when each page has unique useful content.
- Add blog/resources only when the business has real expertise and search demand.
- Improve Core Web Vitals after the page already loads reliably and clearly.
- Add local partner links and real local citations.

### Low Impact / Optional

- Tiny keyword placement tweaks.
- Extra decorative schema.
- Trendy AI-search files.
- Blog content without a distribution or search strategy.
- Rewriting already clear copy just to satisfy an SEO tool score.

## SEO Rule To Remember

For most small-business websites, the first SEO pass should not start with "content strategy."

It should start with:

1. Can Google crawl it?
2. Can users understand it in 3 seconds?
3. Does it load fast enough on a phone?
4. Is the business real and trustworthy?
5. Can the visitor take the next action easily?
6. Is every page language, title, metadata, and URL state correct?

Only after that should we talk about blogs, backlinks, or advanced SEO.
