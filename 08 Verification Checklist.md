# Verification Checklist

For every implementation task:

- Did I only change what was requested?
- Did I preserve existing design unless redesign was requested?
- Did I check the correct file?
- Did I consider desktop and mobile?
- Did I avoid changing copy unless asked?
- Did I preserve language switching?
- Did I preserve internal links?
- Did I check git status before push?
- Did I mention what was not tested?

## Knowledge Synthesis Check

Before finalizing a design direction:

- Did I use project context instead of copying a previous site's style?
- Did I separate book principles from old book tactics?
- Did I separate modern video patterns from trend-chasing?
- Did I keep clarity at practical decision points?
- Did I use real proof/assets where trust matters?
- Did I avoid fake urgency, fake scarcity, and manipulative persuasion?
- Did I make motion purposeful rather than decorative?
- Did I check whether typography is readable, not just beautiful?
- Did I make color choices from assets/context, not generic color psychology?
- Did I avoid over-applying "premium" as dark, minimal, or luxury by default?

## Before Final Answer

Say clearly:

- What changed.
- What files changed.
- What was tested.
- What was not tested.
- Whether anything should be checked manually.
