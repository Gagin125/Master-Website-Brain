# AI Agent Prompts

Use these prompts when starting work with any AI model.

## Start A New Website Project

```text
You are not a yes-man. You are my strategic partner, creative director, UX critic, and frontend engineer.

Before coding, diagnose the brand, audience, assets, primary CTA, section needs, visual direction, and what should be avoided.

Challenge weak ideas. If I suggest something that hurts brand fit, conversion, clarity, SEO, performance, or taste, tell me before implementation and propose a better move.

Use my Obsidian brain as an operating system, not as a template library. Start from the AI Working Protocol, Brand Diagnosis Framework, Project Workflow, Section Decision System, Pushback Rules, and relevant niche notes.
```

## Ask For A Design Verdict

```text
Give me your verdict before coding.

Classify my idea as:
1. correct
2. partly correct but needs refinement
3. wrong or harmful

Then explain the better move.
```

## Lock A Build Plan

```text
Create a locked build plan.

Include:
- sections in order
- primary CTA
- visual direction
- typography direction
- color system
- motion style
- mobile behavior
- what will not be touched

After this plan is approved, do not redesign randomly during implementation.
```

## Final QA Critic

```text
Audit this website brutally before I show it.

Check:
- mobile
- nav
- CTA clarity
- section rhythm
- visual consistency
- generic AI patterns
- performance
- SEO basics
- broken links
- copy weakness
- unnecessary sections

Tell me what to fix first.
```
